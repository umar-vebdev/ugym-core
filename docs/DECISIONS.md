### D-001 — Назначение и границы пакета ugym_core
- Дата: 2026-11-16
- Тип: решение
- Решение: `ugym_core` выделяется в отдельный репозиторий как общий Flutter-пакет для **uGym** и **uGym Business**. В пакет входят только дизайн-система **uCraft 1.0**, сетевое ядро (`Dio` + интерцепторы + `ErrorMapper`), `SecureStorage` и общие форматтеры (`Money`, `Weight`, `Date`). Бизнес-логика конкретных приложений в `ugym_core` запрещена.
- Причина: единый источник правды для UI-токенов и сетевых контрактов без дублирования кода между двумя репозиториями.
- Затронутые разделы ТЗ: `uCraft_Design_System.md` (раздел 21)
- Статус: принято


### D-002 — Сетевые зависимости (dio, flutter_secure_storage) и генерация UUID v4
- Дата: 2026-11-16
- Тип: решение
- Решение:
  1) В `ugym_core/pubspec.yaml` добавляются пакеты `dio` (HTTP-клиент и интерцепторы) и `flutter_secure_storage` (защищённое хранение Bearer-токена в iOS Keychain / Android Keystore).
  2) Генерация UUID v4 для заголовков `X-Request-Id` и `Idempotency-Key` реализуется в чистом Dart через `dart:math` (`Random.secure()`) без добавления отдельного пакета `uuid`.
- Причина: стандартный и надёжный стек из мобильных ТЗ без лишних зависимостей (принципы KISS/YAGNI).
- Затронутые разделы ТЗ: `uGym_Mobile_TZ.md` (разделы 2.3, 2.4), `uGym_Business_Mobile_TZ.md` (раздел 2.3), `C0-04`
- Статус: принято
