### D-001 — Назначение и границы пакета ugym_core
- Дата: 2026-11-16
- Тип: решение
- Решение: `ugym_core` выделяется в отдельный репозиторий как общий Flutter-пакет для **uGym** и **uGym Business**. В пакет входят только дизайн-система **uCraft 1.0**, сетевое ядро (`Dio` + интерцепторы + `ErrorMapper`), `SecureStorage` и общие форматтеры (`Money`, `Weight`, `Date`). Бизнес-логика конкретных приложений в `ugym_core` запрещена.
- Причина: единый источник правды для UI-токенов и сетевых контрактов без дублирования кода между двумя репозиториями.
- Затронутые разделы ТЗ: `uCraft_Design_System.md` (раздел 21)
- Статус: принято
